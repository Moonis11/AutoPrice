# Data

Place permitted marketplace exports here.

- raw/: untouched exports
- processed/: cleaned modelling tables

Recommended columns: make, model, year, mileage_km, transmission, fuel_type, region, condition, price, currency, source, source_url, collected_at.

Do not commit personal contact details or large raw files. Keep asking prices distinct from confirmed transaction prices. Never mix currencies without a dated, documented exchange rate.
